# FinSight Data Infrastructure

FinSight is an end-to-end financial data infrastructure that ingests market
data from external APIs, stores raw records in PostgreSQL, transforms them into
analytics-ready models, validates data quality, and orchestrates the complete
pipeline.

## Core Capabilities

- Automated financial market data ingestion
- Layered raw, staging, and analytics data models
- Reproducible PostgreSQL services using Docker
- SQL transformations and testing with dbt
- Workflow orchestration with Apache Airflow
- Data-quality monitoring and validation
- Interactive analytics dashboard
